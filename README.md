# Personal Planner

**Personal Planner** — Android-приложение для управления повседневными задачами и формирования полезных привычек. Оно объединяет список дел, архив выполненных задач и трекер привычек с сериями выполнения и виджетами рабочего стола.

## Возможности

### Задачи
- Создание и выполнение задач.
- Группировка задач по темам.
- Удаление задач и работа с архивом.
- Восстановление задач из архива.
- Виджет задач для быстрого доступа с главного экрана.

### Привычки
- Создание и отслеживание привычек.
- Ежедневная отметка выполнения.
- Отслеживание серий выполнения привычек.
- Сохранение истории выполнения.
- Виджет привычек и мультивиджет с несколькими выбранными привычками.
- Визуальная обратная связь о выполнении привычек.

### Виджеты
Приложение поддерживает взаимодействие с задачами и привычками непосредственно с главного экрана Android. Виджеты отображают актуальное состояние данных и помогают отслеживать выполнение задач и регулярность привычек.

## Технологии

- **Kotlin** — основной язык разработки.
- **Android SDK** — платформа приложения.
- **Jetpack Compose** — создание пользовательского интерфейса.
- **Android App Widgets** — виджеты главного экрана.
- **SharedPreferences и JSON** — локальное хранение данных отдельных компонентов приложения.
- **Gradle** — сборка проекта.

## Структура проекта

```text
app/src/main/java/com/personalplanner/app/
├── core/       # Инициализация и обработка системных событий
├── manager/    # Управление задачами и привычками
├── model/      # Модели данных
├── storage/    # Сохранение и загрузка данных
├── ui/         # Экраны и компоненты интерфейса
└── widget/     # Виджеты Android и их конфигурация
```

Ресурсы интерфейса, изображения, иконки и XML-разметки находятся в `app/src/main/res/`.

## Установка

### Скачать APK

**[Скачать Personal Planner (APK)](https://github.com/LizaVeprova301/Personal-Planner/raw/refs/heads/main/app-release.apk)**

### Установка на Android

1. Откройте ссылку выше на телефоне и скачайте файл `app-release.apk`.
2. Откройте скачанный APK-файл.
3. Если Android попросит разрешение на установку приложений из этого источника, разрешите установку в настройках.
4. Нажмите **«Установить»** и дождитесь завершения.
5. Откройте Personal Planner.

Если система предупредит о неизвестном источнике приложения, убедитесь, что APK скачан из официального репозитория проекта, и разрешите установку, если доверяете источнику.

> **Важно:** приложение распространяется напрямую в формате APK и не размещено в Google Play. Для установки требуется Android-устройство.

## Запуск из исходного кода

Для разработки и самостоятельной сборки:

1. Установите Android Studio.
2. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/LizaVeprova301/Personal-Planner.git
   ```

3. Откройте проект в Android Studio и дождитесь синхронизации Gradle.
4. Подключите Android-устройство или запустите эмулятор.
5. Нажмите **Run** для запуска приложения.

Чтобы собрать APK самостоятельно, выберите **Build → Build APK(s)** в Android Studio.
